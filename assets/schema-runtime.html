Schema runtime

ChatGPT App — deterministic schema runtime with model-authored schemas.

Validation now runs without mounting, so a schema can be checked before anything is built. Every failure is a structured object: code, node, path, expected, got, and a fix.

Patches are addressed by node id. Type into the filter first — that state should survive the recompose.

No patch applied yet.

Each fixture is a schema with the exact set of error codes it should produce. A pass means the validator found those and nothing else — over-reporting fails as loudly as under-reporting.

ChatGPT is the model. Describe the UI you want. This sends a follow-up message into the conversation and asks ChatGPT to author a schema and call the app's render_schema tool. No API key is stored or exposed to the widget.

You can also ask ChatGPT directly in the conversation, e.g. “Use Schema Runtime to build a filtered spending dashboard.”

Blue keys are written by components. Teal keys are derived and read-only.
